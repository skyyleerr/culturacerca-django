## Product Goal
Facilitar la exploración de espacios culturales registrados en Colombia mediante información oficial, una interfaz web y búsqueda por municipio.

## Sprint Goal — 14/11/2026
Entregar una primera versión navegable en Django que permita consultar registros reales y filtrar por municipio.
